# Zotero 飞书同步

[English](../README.md)

Zotero 飞书同步是一个非官方 Zotero 插件，用于将文献元数据、笔记、图片和
PDF 附件发布到飞书云文档。此 0.8.0-beta.4 修改版支持原 PDF／网页快照批注
到既有英文全文文档的选区评论同步；逐节精读、中文全文、英文全文阅读 PDF 的
批注分别同步到各自对应文档。直接复用插件原授权和飞书客户端。
安装 XPI 后即可连接飞书，无需 lark-cli、Python 或桥接服务。

有“飞书文档映射”子笔记的文献走批注同步；其余条目保留原导出行为。
详细规则见[批注同步说明](mapped-annotations.md)。

## 使用要求

- Zotero 8–10；此候选版在 Zotero 10.0.8 中测试。
- 中国大陆飞书账号，并且能够创建个人应用和授予所需权限。组织策略可能要求
  管理员审批。
- 同步时，Zotero 必须能够访问本地 PDF 和笔记图片文件。

## 安装

1. 使用本候选版产物目录中的 `zotero-feishu-note.xpi`；此版本尚未发布到上游。
2. 在 Zotero 中打开 **工具 → 插件**。
3. 选择**从文件安装插件**，打开 XPI，并在 Zotero 提示时重启。

## 连接飞书

1. 打开 **Zotero 设置 → zotero-feishu-note**，点击**连接飞书**。
2. 在浏览器中确认创建专用个人应用。
3. 如果打开飞书权限管理页，请开通列出的权限，并完成组织要求的应用发布或
   管理员审批。
4. 在浏览器中完成账号授权，然后返回 Zotero。

已有授权缺少评论权限时点击“补充授权”；新授权包含评论读取、创建和更新权限。
不需要手动填写 App ID、App Secret 或重定向地址。同步位置留空时使用“我的
空间”根目录，也可以填写飞书云空间文件夹链接或 Token。

## 使用方法

- 右键点击普通文献、文献的子笔记或子附件，选择
  **飞书同步 → 同步选中文献**。
- 右键点击分类，选择**同步当前分类到飞书**。
- 在相同菜单中打开或明确删除条目对应的飞书文档。
- 在飞书状态列查看同步中、成功或失败详情。

每篇普通文献对应一个飞书 Docx。插件确认映射文档仍存在后，会跳过内容没有
变化的条目。子笔记会保留与 Markdown 对应的结构，笔记图片会被上传，本地
子 PDF 会被追加到文档末尾。

## 原文批注与多机同步

两台机器可以都开启自动同步，并分别连接同一飞书账号。保存高亮／下划线后，
默认等待 1.5 秒再同步。内容未变跳过，修改批注更新原评论，不同批注分别上传。
新机器自动发现映射笔记，从评论末尾的不可见来源编码恢复关联，不依赖 Syncthing
或共享本地索引。旧版可见后缀会原位迁移。编码属于 Unicode 文本，并非飞书原生
隐藏字段，复制评论可能携带；手动编辑或导出时若被清除，该评论将无法恢复关联。
Zotero 自身的数据仍需同步。

同时首次上传时可能短暂出现重复。各机器统一选最小评论 ID；确认没有后续回复
或独立修改的重复评论会添加关联标记并标为已解决，保留历史。已有讨论会保留并
提示待处理。同步变更后 30 秒复核，之后默认每 300 秒复核；这是自动收敛，
不承诺服务端事务锁或“从未短暂重复”。不需要指定主机或手动切换开关。

设置页包含原文批注总开关、自动／仅手动、全部映射／指定分类（含子分类）、等待时间（0.5–300 秒）、失败重试（30–3600 秒）、多机
核对（60–3600 秒）、宽松匹配、纯高亮、预览、手动同步、连接检测与最近 100 次记录。

## 当前限制

- 仅支持“我的文库”和中国大陆飞书。
- 不支持独立笔记和独立附件；选择文献下的子笔记或子附件时会同步其父文献。
- 原导出模式需要先将 PDF 标注添加到笔记；映射批注模式直接读取原文标注。
- 不把飞书编辑导回 Zotero。原导出模式可能覆盖托管内容；映射批注模式保留正文、
  图片、公式、样式和其他评论，独立修改过的评论会提示冲突。
- 原导出映射保存在本机，丢失可能另建文档；论文映射随 Zotero 子笔记同步，
  评论关联可远端恢复。每台机器需分别授权。

## 隐私与移除

文献内容由 Zotero 直接发送到飞书，不经过开发者运营的中转服务器。应用凭据
和 OAuth Token 保存在 Zotero 的 Firefox Login Manager 中；条目映射保存在
`<Zotero 配置目录>/zotero-feishu/state.json`。批注检查点、待处理、核对计划和
历史在同目录 `annotations.json`。本修改版移除了上游自动更新地址，后续版本
手动安装，避免被原版覆盖。

断开连接会删除 OAuth Token，但会保留自动生成的应用凭据，以便下次重新连接。
卸载插件不会删除飞书中的个人应用或已同步文档；不再使用时，请在飞书开放平台
和云空间中手动删除。

## 开发

```bash
npm install
npm start
npm run lint:check
npm run build
npm test
```

将 `.env.example` 复制为 `.env`，并使用专用 Zotero 开发配置目录。生产 XPI 和
更新清单位于 `.scaffold/build/`。
